
# Repositorio de prácticas - Ingeniería de Software II

## Descripción

Este repositorio contiene las prácticas desarrolladas durante la asignatura Ingeniería de Software II, aplicando principios de diseño de software, pruebas, refactorización y documentación de arquitectura.

## Práctica 5: Clínica de código

Se realizó una refactorización de un módulo de cálculo de ventas, aplicando:

- Código limpio.
- Principio de responsabilidad única (SRP).
- Extracción de constantes.
- Pruebas unitarias.
- Uso de Git y Pull Requests.

## Práctica 6: Arquitectura C4

Se documenta la arquitectura del sistema de inventario agrocomercial.

### Funcionalidades del sistema

- Registrar productos.
- Consultar productos disponibles.
- Registrar ventas.
- Calcular el total de las ventas.
- Descontar automáticamente las cantidades vendidas del inventario.

### Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Python
- Supabase
- PostgreSQL

### Documentación

El archivo `practica-6/arquitectura.md` contiene:

- Diagrama C4 nivel 1: contexto.
- Diagrama C4 nivel 2: contenedores.
- Justificación de decisiones arquitectónicas.
- Correcciones realizadas al borrador generado con IA.
